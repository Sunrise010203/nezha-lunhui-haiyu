# Combat VFX Integration Implementation Plan

**Goal:** 将已生成的六类纹理和 Blender 网格接入当前战斗，不改变伤害、判定、消耗和解锁条件。

**Architecture:** 用独立 CombatVFX 工厂缓存纹理／网格，短生命周期组件负责缩放、移动、UV 流动和淡出。技能脚本仅在原有动作／命中事件处调用；持久水膜跟随玩家并由定潮状态驱动。每关加载预热、数量上限和自动回收控制开销。

**Tech Stack:** Godot 4.6.3 GDScript、spatial Shader、现有 PNG 与 GLB。

用户已要求直接接入，本计划在当前会话顺序执行，不另行请求审批，也不提交仓库内其他未提交改动。

## 1. 资源与材质层

- 新建 `001/scripts/combat_vfx.gd`、`001/scripts/vfx_instance.gd`。
- 新建发光／普通透明两种 Shader，正确使用 straight Alpha；烟雾避免加法混合。
- 缓存网格和纹理，禁止新增灯光，限制临时效果数量；绑定场景生命周期。

## 2. 接入战斗事件

- `player.gd`：普攻／重击在出招帧显示枪芒；命中时显示闪光；真火与下砸使用火环／壳体、烟雾和碎片；风火轮替换球形尾焰；定潮水膜／符文、弹反水花和引潮喷射。
- `ring_throw.gd`：短流光尾迹与命中闪光。
- `projectile.gd`：我方潮弹消散水花。
- `breakable.gd`、`enemy_base.gd`：破碎物／敌人死亡的少量碎片。
- `game.gd`：加载阶段预热新增资源。

## 3. 验证

- Godot 编辑器无头导入和脚本解析。
- 新增实战探针验证挥空可见、左右朝向、实际命中数值、技能耗能、定潮取消／死亡隐藏、资源可加载及临时效果回收。
- 使用真实渲染器截取实际关卡中的轻击、真火、下砸、定潮和引潮画面，检查透明边框、遮挡和曝光。
- 记录渲染统计，区分特效开销与现有场景基础开销；运行受影响的既有武器检查。
- 保存接入说明与截图，列明尚未覆盖的表现。

## 完成记录

已接入并完成 13 项特效回归、34 项武器检查和四章加载检查。真实渲染截图覆盖重击、定潮、真火、下砸及弹反；引潮喷射已接入释放事件，尚无单独截图。全场景 draw calls 仅作记录，未建立独立特效性能基准。详情见根目录 `特效接入说明-2026-10-21.md`。
